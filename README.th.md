# Talat Tha Na Map

*[Read in English](README.md)*

เว็บแอปพลิเคชันแผนที่ดิจิทัลและระบบสะสมตราประทับ (Digital Stamp) ผ่าน QR Code สำหรับ **ตลาดท่านา** ตลาดชุมชนริมแม่น้ำนครไชยศรีที่มีอายุกว่า 140 ปี ตั้งอยู่ที่ตำบลนครไชยศรี อำเภอนครไชยศรี จังหวัดนครปฐม โครงการนี้เป็นส่วนหนึ่งของ Community Engagement Program (CEP) โดยนักเรียนโรงเรียนมหิดลวิทยานุสรณ์

## หลักการและเหตุผล

ตลาดท่านามีรากฐานมาตั้งแต่สมัยรัชกาลที่ 1 และพัฒนาเป็นชุมชนค้าขายสำคัญในสมัยรัชกาลที่ 5 ชื่อ "ตลาดท่านา" มาจากการที่บริเวณนี้เคยเป็นท่าเรือสำหรับซื้อขายและขนส่งข้าวเปลือก ข้าวสาร ปัจจุบันตลาดประสบปัญหาจำนวนนักท่องเที่ยวลดลง จากการย้ายออกของร้านอาหารชื่อดัง ประกอบกับปัญหาการขาดระบบนำทางและข้อมูลสำหรับนักท่องเที่ยว ทำให้ผู้มาเยือนไม่ทราบว่าแต่ละร้านจำหน่ายสินค้าประเภทใด ไม่มีเส้นทางแนะนำไปยังจุดที่น่าสนใจ และไม่สามารถเข้าถึงเสน่ห์ที่ซ่อนอยู่ภายในชุมชนได้อย่างเต็มที่

โครงการนี้จึงเสนอให้นำเทคโนโลยีเข้ามาแก้ไขปัญหาดังกล่าว ด้วยการพัฒนาแผนที่ดิจิทัลของตลาดชุมชน และออกแบบกิจกรรม Walk-Rally ที่ใช้ระบบสแกน QR Code เพื่อเพิ่มการมีส่วนร่วมของนักท่องเที่ยว กระตุ้นให้สำรวจตลาดอย่างครบถ้วน และสร้างโอกาสทางการค้าให้แก่ผู้ประกอบการในชุมชนอย่างยั่งยืน

## วัตถุประสงค์

พัฒนาระบบแผนที่ดิจิทัลและระบบสะสมตราประทับ (Digital Stamp) ผ่านการสแกนคิวอาร์โค้ด (QR Code) ที่จุดต่าง ๆ ภายในตลาด

## กลุ่มเป้าหมาย

- **ผู้ใช้งานแอปพลิเคชัน:** นักท่องเที่ยวที่ไม่คุ้นเคยกับตลาดท่านา
- **ผู้ได้รับประโยชน์:** ผู้ประกอบการและพ่อค้าแม่ค้าในพื้นที่

## ผลลัพธ์ที่คาดหวัง

1. เพิ่มการกระจายรายได้สู่ร้านค้าในชุมชน โดยกระตุ้นให้นักท่องเที่ยวใช้เวลาและจับจ่ายใช้สอยภายในตลาดท่านานานขึ้น
2. พัฒนาระบบนำทางและอำนวยความสะดวกภายในตลาด เช่น แผนผังตลาด ระบบ QR Code ประจำจุดต่าง ๆ และข้อมูลพิกัดร้านอาหาร เพื่อให้ผู้มาเยือนสำรวจพื้นที่ได้อย่างครบถ้วนและไม่สับสน อีกทั้งใช้เป็นเครื่องมือวัดผลการกระจายตัวของนักท่องเที่ยว
3. ส่งเสริมการท่องเที่ยวเชิงประวัติศาสตร์และวัฒนธรรม ผ่านการสื่อสารความเป็นมาของตลาดท่านาให้แก่ผู้มาเยือน

รายละเอียดข้อเสนอโครงการฉบับเต็ม (หลักการ, แผนดำเนินงาน, งบประมาณ, การประเมินผล) อยู่ที่ [CEP_ข้อเสนอโครงการ.md](CEP_ข้อเสนอโครงการ.md)

## เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
|---|---|
| Frontend | TypeScript + React (Vite) |
| Backend | Python + FastAPI พร้อมการเข้ารหัสข้อมูลที่จัดเก็บ |
| Analytics | Python (pandas, matplotlib) สำหรับประมวลผลและสรุปข้อมูล |

ดูโครงสร้างโปรเจกต์ทั้งหมดและเหตุผลของแต่ละส่วนได้ที่ [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md)

## เริ่มต้นใช้งาน

```bash
# Frontend
cd frontend
npm install
npm run dev

# Backend
cd backend
pip install -r requirements.txt
cp .env.example .env   # กรอกค่า DATABASE_URL และ ENCRYPTION_KEY
uvicorn app.main:app --reload

# Analytics
cd analytics
pip install -r requirements.txt
```

## ทีมพัฒนา

**หัวหน้าโครงการ:** นายณรงค์วัส วาจรัต

**ผู้ร่วมทีมพัฒนา:**
- นางสาวปารณีย์ หอสุวรรณานนท์
- นายญาณวุฒิ นิลทรัตน์
- นางสาวชนัญชิดา บุญไชยโย
- นายธนภัทร เธียรจินดากุล
- นายศิลปะ ชัยบุรัมย์
- นายรัชชานนท์ ชานันโท
- นายกิตติพิชญ์ คุณรักษ์พงศ์

ผู้พัฒนาโครงการทั้งหมดมาจากโรงเรียนมหิดลวิทยานุสรณ์

**ที่ปรึกษาโครงการ:**
- นางสาวดวงแข ศรีคุณ — สาขาวิชาเคมี โรงเรียนมหิดลวิทยานุสรณ์
- นางสาวเกล็ดทราย ภูผาคุณ — สาขาวิชาฟิสิกส์ โรงเรียนมหิดลวิทยานุสรณ์
- นายบุญฤทธิ์ พูนพนิช — คณะศิลปวิจิตร สถาบันบัณฑิตทัศนศิลป์
- นายนิชชาฌ ปัญจกาญน์มณี — ผู้ใหญ่บ้านชุมชนตลาดท่านา
