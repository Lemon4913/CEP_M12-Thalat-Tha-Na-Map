ตลาดริมน้ำที่มีอายุกว่า 140 ปี ย่านการค้าสำคัญของลุ่มน้ำนครชัยศรี รากเหง้าของชุมชนไทย-จีน
⛵
ยุคแรก · รัชกาลที่ 4–5
กำเนิดท่าเรือขนข้าว
›

ตลาดท่านาเริ่มต้นจากท่าเรือขนาดเล็กริมแม่น้ำนครชัยศรี ในสมัยรัชกาลที่ 4-5 ชาวนาและพ่อค้าจากทั่วลุ่มน้ำนำข้าวเปลือกมาส่งที่ท่าเรือแห่งนี้ ก่อนส่งต่อไปยังกรุงเทพฯ

ชาวจีนโพ้นทะเลที่อพยพมาตั้งรกรากเป็นกลุ่มแรกๆ ที่เปิดร้านค้าริมท่าน้ำ สร้างห้องแถวไม้สักเรียงรายตลอดสองฝั่งถนน รูปแบบสถาปัตยกรรมที่เห็นได้จนถึงทุกวันนี้

🏮
รุ่งเรือง · รัชกาลที่ 6–7
ยุคทองของตลาดริมน้ำ
›

ช่วงต้นศตวรรษที่ 20 ตลาดท่านาเจริญรุ่งเรืองที่สุด มีเรือสำปั้นเทียบท่าวันละหลายสิบลำ ร้านค้าเปิดตั้งแต่ดึก พ่อค้าแม่ค้าจากหลายจังหวัดมาซื้อขายสินค้า

ศาลเจ้าอาม่าถูกสร้างขึ้นในยุคนี้ เป็นศูนย์กลางจิตใจของชุมชนชาวจีน มีการจัดงานประเพณีประจำปีที่ดึงดูดผู้คนจากหลายอำเภอ

ส้มโอพันธุ์นครชัยศรีเริ่มเป็นที่รู้จักในยุคนี้ เกษตรกรริมน้ำพัฒนาพันธุ์พิเศษที่ปลูกได้ดีบนดินตะกอนริมแม่น้ำ

🌾
สถาปัตยกรรม
ห้องแถวไม้ · มรดกที่ยังหายใจ
›

ห้องแถวไม้สักสีเหลืองที่เห็นอยู่ในปัจจุบันสร้างขึ้นในสมัยรัชกาลที่ 5-6 มีลักษณะเป็นสถาปัตยกรรมแบบชิโน-โปรตุกีส ผสมผสานรูปแบบจีนกับอิทธิพลตะวันตก

ลวดลายฉลุไม้เหนือประตูหน้าต่างเป็นฝีมือช่างท้องถิ่น แต่ละหลังมีลวดลายไม่ซ้ำกัน เป็นภูมิปัญญาที่ส่งต่อกันมาหลายรุ่น

อาคารเหล่านี้ยังคงมีผู้อยู่อาศัยและประกอบกิจการ ทำให้ตลาดท่านาเป็นชุมชนที่ "ยังมีชีวิต" ไม่ใช่แค่พิพิธภัณฑ์กลางแจ้ง

🍊
อาหารและวัฒนธรรม
รสชาติที่หาไม่ได้ที่ไหน
›

ส้มโอนครชัยศรีได้รับการขึ้นทะเบียนสิ่งบ่งชี้ทางภูมิศาสตร์ (GI) ดินตะกอนริมแม่น้ำและสภาพอากาศพิเศษของพื้นที่ทำให้ส้มโอที่นี่มีรสชาติเฉพาะตัว

เป็ดพะโล้สูตรดั้งเดิมของชุมชนจีน ปรุงด้วยสมุนไพรและเครื่องเทศที่นำเข้ามาจากจีนในยุคแรก สูตรนี้ถ่ายทอดกันมากกว่า 3 รุ่น

ขนมปังเย็นและบัวลอยเป็นอาหารพื้นถิ่นที่กำเนิดมาจากการผสมผสานวัฒนธรรมไทยและจีน ที่เกิดขึ้นโดยธรรมชาติในชุมชนนี้
