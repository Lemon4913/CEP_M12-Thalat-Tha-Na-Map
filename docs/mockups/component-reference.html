Colour DOCS/03-DESIGN-SYSTEM.MD

Cream is the background. Green is the frame. Gold is the reward — it means “you earned this”, so it never gets used decoratively. Never set gold text on cream; contrast fails outdoors, which is where this app is used.

Typography SARABUN ONLY

Sarabun covers Thai and Latin in one family. Never substitute system-ui or a generic sans fallback — Thai tone marks and diacritics break. Thai text never gets letter-spacing; uppercase Latin labels take 0.04em.

Stamp states THE CORE OBJECT

A stamp can never be un-earned, and can only come from a scan — there is no “mark as visited” affordance. Locked uses --cream-md, never opacity on a coloured element; opacity washes out in sunlight.

EARNED
LOCKED
Just earned: brief --gold-lt glow and slight scale over 0.2s, settling into Earned. Nothing longer — someone is standing in the sun waiting.
Never colour alone: earned also changes border weight, icon saturation and adds the gold dot.

Buttons ONE STYLE, ON PURPOSE

There is no secondary button style. If you need one, add it to the design system first — don't invent it inside a component.

Bottom-sheet modal PIN / STAMP DETAIL

Opens on tapping a map pin or a stamp. Dismiss by tap-outside or swipe-down. If the spot isn't earned yet, the historical fact is hidden — unlocking history is part of the reward loop.

Rules that are easy to break READ BEFORE BUILDING

UI copy stays ThaiCode, comments and docs are English. Don't translate interface strings “for clarity” — the users are Thai visitors standing in the market.
Give Thai vertical roomThai stacks vowels and tone marks above and below the line. Never tighten leading or shrink type to make a layout fit — cut copy instead.
Tap targets ≥ 44pxOne-handed, walking, in sunlight, possibly holding a bag of pomelo. No exceptions on the nav or the map pins.
Assume the network dropsRiverside 4G is unreliable. Progress must survive a dropped connection; queue writes and reconcile.
Don't let the client decide 7/7The reward is a physical print that costs money. Redemption eligibility is verified server-side, single-use.
Don't collect more than you needReal people in a real community. Anonymous session, scan events, nothing more. No accounts, no personal identifiers.
