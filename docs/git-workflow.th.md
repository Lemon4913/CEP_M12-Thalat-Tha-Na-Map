# Git Workflow ง่ายๆ สำหรับทีม (ทำตามนี้ทุกคน)

## ภาพรวม

คิดง่ายๆ: มี "ห้องกลาง" (`main`) ที่ต้องรันได้เสมอ ห้ามใครแก้ตรงนั้นตรงๆ
แต่ละคนมี "ห้องส่วนตัว" (branch) ของตัวเอง ทำงานในห้องตัวเองจนพอใจ
แล้วค่อยขอเอาไปรวมกับห้องกลาง

```
main  ──●──────●──────●──────►  (ต้องรันได้เสมอ)
          \            ↑
           ●──●──●─────┘   feature/map-pages (คนที่ 1)
```

## 1) ทำครั้งเดียวตอนเริ่ม

```bash
git clone <ลิงก์ repo>          # ดึงโค้ดมาไว้ในคอม (ทำครั้งเดียว)
cd CEP_M12-Thalat-Tha-Na-Map
git checkout -b feature/ชื่องานของฉัน   # สร้างห้องส่วนตัว เช่น feature/map-pages
```

ใครทำงานอะไรก็ตั้งชื่อ branch ตามงานนั้น (ตามที่แบ่งไว้ 5 อัน)

## 2) ก่อนเริ่มทำงานทุกครั้ง (สำคัญ — ทำทุกวันที่จะเริ่มโค้ด)

```bash
git checkout feature/ชื่องานของฉัน   # เข้าห้องตัวเอง
git pull origin main                # ดึงของใหม่จาก main มาผสมกับห้องเรา
```

ทำแบบนี้ก่อนเริ่มทำงานเสมอ เพื่อไม่ให้ห้องเราตกยุคจนงานคนอื่นชนกับเรามาก

## 3) ระหว่างทำงาน (ทำซ้ำได้เรื่อยๆ)

```bash
git add .                     # เก็บไฟล์ที่แก้แล้วลงกล่อง
git commit -m "อธิบายสั้นๆว่าแก้อะไร"   # เซฟเป็นจุด checkpoint
git push origin feature/ชื่องานของฉัน   # ส่งขึ้น GitHub (ห้องส่วนตัวบนคลาวด์)
```

push บ่อยๆ ได้เลยแม้งานยังไม่เสร็จ — นี่ไม่ใช่ main เลยไม่กระทบใคร

## 4) เมื่ออยากรวมงานเข้า main

1. เข้า GitHub → กด **"Compare & pull request"** (หรือ New Pull Request)
2. เลือก: จะเอา branch ของเรา → รวมเข้า `main`
3. เขียนอธิบายสั้นๆว่าทำอะไรไปบ้าง
4. แท็กคนรีวิวตามคู่ที่กำหนด (คนที่1↔3, คนที่2↔4, คนที่5 รีวิวรอบสุดท้าย)
5. คนรีวิวกดอ่าน ถ้าโอเคกด **Merge** — งานเราเข้า main แล้ว 🎉

## ถ้าเจอ "Conflict" (คำเตือนสีแดงตอน merge) — ไม่ต้องตกใจ

Conflict = มีคนแก้ไฟล์เดียวกัน บรรทัดเดียวกัน กับเรา แปลว่า Git งงว่าจะเก็บของใคร

- **ห้ามกดเลือกฝั่งใดฝั่งหนึ่งมั่วๆ** ไปคุยกับเจ้าของอีกฝั่งก่อนว่าอันไหนถูก แล้วแก้ไฟล์ให้ถูกด้วยมือ
- ไฟล์ที่เจอ conflict บ่อยสุด: `backend/app/api/routes.py` และ `backend/app/schemas.py`
  (คนที่ 3, 4 ใช้ร่วมกัน) — ก่อนแก้ไฟล์นี้ ทักเพื่อนในกลุ่มก่อนว่ากำลังจะแก้อะไร

## สรุปกฎ 3 ข้อที่ต้องจำ

1. **ไม่แก้ main ตรงๆ** — ทำในห้องตัวเอง (branch) เสมอ
2. **pull ก่อนเริ่ม, push บ่อยๆ** — ลดโอกาสชนกัน
3. **conflict = คุยกันก่อน** ไม่ใช่เลือกมั่วๆ
